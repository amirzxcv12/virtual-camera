# 📷 Python Virtual Camera

A simple virtual camera project built with **Python** and **OpenCV**.

This project loads an image (`photo.jpg`), resizes it to 1280×720 resolution, and displays it in a camera-style window.

## ✨ Features

- Load images using OpenCV
- Resize images to 1280×720
- Real-time window display
- Press `Q` to close the application
- Simple and beginner-friendly Python code

## 🛠️ Requirements

- Python 3
- OpenCV

## 📦 Installation

Install OpenCV:

```bash
pip install opencv-python
```

## 🚀 Usage

1. Clone this repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Put your image inside the project folder and name it `photo.jpg`.

3. Run the program:

```bash
python3 main.py
```

## ⌨️ Controls

| Key | Action |
|---|---|
| Q | Exit |

## 📸 Preview

The program displays your selected image in a 1280×720 window.
